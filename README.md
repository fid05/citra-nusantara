## About

Citra Nusantara is the Malay poetry club of Universiti Teknologi PETRONAS (UTP), Seri Iskandar. The club writes, performs and competes in pantun, sajak and spoken word, and organises its own annual pantun competition, the **Sayembara Pantun Piala Mestika Embun**.

This website is the club's home online. It is written fully in Bahasa Melayu and designed around Malay heritage: hikayat manuscript pages, carved timber from the traditional Malay house, songket bands, awan larat carving and Jawi script.

> This repository is a showcase of the website. The source code is not included.

## Permainan: four mini games

The Permainan section is the horror corner of the site, with drifting mist and glowing eyes that blink in the dark. Every game draws from a bank of 200 questions about Malaysian history, legends, food, flora and fauna, traditions and language, and players never see the same questions in the same order twice.

### Polaroid Citra

At the end of each game, players can take a souvenir photo inside a frame made for that game, as one photo or a three photo collage, then download or share it. The photo is made entirely on the player's own device and is never uploaded or stored.

## Highlights

- **Malay heritage design** built from hikayat manuscripts, the Malay house, songket and awan larat carving, with Jawi script
- **Gamelan and seruling music** composed and played entirely in code with the Web Audio API, no audio files
- **A different animation for every section**: bunga raya petals, ink-like headings, opening shutters, unrolling scrolls, a floating wau bulan, kunang-kunang and a misty horror corner
- **Four mini games** with a shared 200 question bank, moving atmospheres and a polaroid souvenir at the end
- **Easy for the committee to update**: achievements, events, products and the about text are edited in a Google Sheet, no coding needed
- **Accessible**: works on phones, has a dark mode, and turns motion off for visitors who prefer reduced motion

## Built with

HTML, CSS and JavaScript, the Web Audio API, the Canvas API, Google Sheets as the content source, and Firebase Hosting.
